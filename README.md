# 📌 Project Overview

This portfolio website showcases my skills, experience, and software development projects as a Software Developer and Data Science graduate.

The website was built using React and Vite to provide a fast, responsive, and modern user experience while highlighting projects ranging from Machine Learning applications to full-stack web development.
